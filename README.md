# Small Enough to Build

**How small can something get before it stops looking like itself?**

A photograph holds millions of values. A twenty-three brick dog holds twenty-three
decisions. This project is about the throwing away — turning one photograph into a
small, buildable brick model, and arguing about what survives.

A year-long project by Suchandra Chakraborty, currently at the question stage.

**Live site:** https://suchandrac.github.io/small-enough-to-build/

## What's here

A single self-contained page (`index.html` — no build step, no dependencies, no
framework). It includes:

- An interactive brick model you can drag to rotate and build layer by layer,
  drawn as isometric SVG
- A walkthrough of the pipeline from photo to buildable model
- A short feedback form, because the project is still at the stage where the
  questions matter more than the answers

## Running it locally

Clone it and open `index.html` in a browser. That's the whole thing.

```
git clone https://github.com/SuchandraC/small-enough-to-build.git
open small-enough-to-build/index.html
```

## Feedback

The form at the bottom of the site is real and the replies get read. If you'd
rather not use it, open an issue.
